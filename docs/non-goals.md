# Non-goals

These are explicitly outside Phase 0/1 and must not be implied by the current
scaffold:

- GitHub, GitLab, Bitbucket, or Azure DevOps integration.
- Automatic merge, push, or silent modification of a developer branch.
- Automatic fixing, multi-agent workflows, vector databases, or IDE extensions.
- A dashboard before the core engine is useful.
- Production credential access, real GitHub credentials, or broad write access.
- Executing arbitrary repository code or downloading unknown dependencies.
- Support for every programming language; TypeScript and Python are only the
  initial adapter targets.
- Calling a finding validated without running the configured validation checks.
